### 2. Grabación de Pantalla en Dispositivo Físico (B-Roll):
Se puede capturar directamente la pantalla del Moto G22 conectado por ADB para obtener tomas de vídeo reales de 60 FPS:
```powershell
# Comando para grabar pantalla en tiempo real en el Moto G22:
adb -s ZT322B386P shell screenrecord --size 1280x720 --bit-rate 6000000 /sdcard/red_demo.mp4
# Para descargar el archivo al PC:
adb -s ZT322B386P pull /sdcard/red_demo.mp4 ./promo_assets/
```
